# Which weeks fit the phrase bank format

The format works best when students can write true sentences about
themselves from a bank of everyday phrases. It works less well for
story-based or text-based grammar (narrative past tenses, passive, reported
speech, reading the news). Mark a week as done once its worksheet is made.

Ratings: ★★★ great fit · ★★ good fit · ★ skip or adapt heavily

| Week | Grammar | Fit | Angle (forms row / key / bank / partner question) | Done |
|---|---|---|---|---|
| 6 | Your Week in English (adverbs of frequency) | ★★★ | `adverbs-of-frequency.html` | ✅ |
| 7 | Zero + First Conditional | ★★★ | Pair: zero (if + present, present) vs first (if + present, will). Key: comma when *if* is first, no *will* after *if*. Bank: conditions (it rains, I'm late, my kid is sick) + results. Partner: "What do you do if...?" `zero-first-conditional.html`: everyday situations, not voting (most students can't vote) | ✅ |
| 7 | Let's Make a Suggestion | ★★ | Better as a short add-on strip to the week 7 sheet (Let's / Why don't we / How about + -ing) than its own sheet | |
| 8 | Can, Should, Must | ★★★ | Forms: can / can't / should / shouldn't / must. Key: modal + base verb (✗ *can to go*, ✗ *she cans*). Bank: phone and family tasks. Partner: "What can you do / should you do...?" | |
| 9 | Have You Ever...? | ★★★ | Forms: base / V3 chart. Key: have + V3, *ever* in questions, *never* in answers, follow-up in past simple ("When did you...?"). Bank: experiences written as V3 (eaten sushi, been to New York, ridden a horse). Partner: classic "Have you ever...?" interview | |
| 9 | Just, Already, Yet | ★★★ | Natural sequel to the adverbs position key: *just* / *already* between have and V3, *yet* at the end, *yet* only in questions and negatives. Bank: errands and to-do list items. Could share a sheet with "Have you ever" | |
| 10 | What Are You Good At? | ★★★ | Forms: good at / bad at / interested in / not very good at. Key: preposition + noun or -ing (✗ *good at cook*). Bank: skills (cooking, fixing things, drawing, math, talking to people). Partner: "What are you good at?" | |
| 11 | How Long + For and Since | ★★★ | Timeline row: *for* + amount of time vs *since* + start point. Key: have lived / have worked + for/since, "How long have you...?". Bank: life facts (live in Boston, work at..., study English, know my best friend). Partner: "How long have you...?" | |
| 12 | Comparatives + Superlatives | ★★ | Forms: -er / more / the -est / the most. Bank: adjectives + things to compare (stores, phones, cities, transport). Less personal, so add an opinion frame: "I think ___ is ___er than ___ because..." | |
| 13 | How Much / How Many | ★★ | Better as a sort: the bank is split into countable / uncountable columns. Partner: "How much coffee / How many hours do you...?" | |
| 14 | Understanding the News | ★ | Text-based. Skip | |
| 15 | Fall Review | ★★ | Mixed sheet: one row per tense, with the bank reused from earlier sheets | |
| 16 | Asking the Right Questions About Housing | ★★ | Question-word key (Is there / Are there / How much / Can I). Bank: apartment features | |
| 17 | Have to / Don't Have to / Can't | ★★★ | Forms: have to / don't have to / can't. Key: has to for he/she, *don't have to* ≠ *can't*. Bank: rules at home, at work, in an apartment | |
| 18 | Need to / Want to / Hope to (infinitives) | ★★★ | Key: verb + to + base. Bank: housing and life goals. Partner: "What do you need to do this month?" | |
| 19 | Past continuous: It Was Happening When | ★ | Story-based. Use a picture story instead | |
| 20 | Past Perfect | ★ | Story-based | |
| 21 | Used to | ★★★ | Two-column "then / now" layout: *I used to ___, but now I ___*. Key: *didn't use to*, ✗ *I use to* in the past. Bank: jobs, routines, food, transport back home | |
| 21 | Must / Have to / Should at Work | ★★ | Reuse the week 8 and 17 keys with a workplace bank | |
| 22 | Second Conditional | ★★★ | Key: if + past, would + base; *If I were*. Bank: dream situations (won the lottery, spoke perfect English, had a free day). Partner: "What would you do if...?" | |
| 23 | Enjoy Doing vs Want to Do | ★★★ | Two-bin key: enjoy / like / don't mind / finish + -ing vs want / need / hope / plan + to. Bank: work activities | |
| 23 | Phrasal Verbs at Work | ★★ | Bank is the phrasal verbs themselves. Key: separable or not | |
| 24 | Just, Already, Yet: Job Search | ★★ | Reuse the week 9 sheet with a job-search bank | |
| 25 | Present Perfect Continuous | ★★ | "I've been ___ing for/since". Reuses the week 11 timeline | |
| 26 | Past Perfect Continuous | ★ | Story-based | |
| 27 | Passive Voice | ★ | Text-based (pay stubs) | |
| 28 | Should / Shouldn't: Health Advice | ★★★ | Bank: health habits and problems. Partner: give advice for a problem card | |
| 29 | Stop Doing vs Stop to Do | ★★ | Two-bin key like week 23. Small bank | |
| 30 | Reported Speech | ★ | Dialogue-based | |
| 31 | Third Conditional | ★★ | Personal regrets can be sensitive. Use light, everyday situations (missed the bus, forgot my umbrella) | |
| 32 | Future Perfect | ★★ | Bank of goals + dates: "By June, I will have ___" | |
| 33 | Be Used to / Get Used to | ★★★ | Forms: am used to / am getting used to / am not used to + -ing or noun. Bank: life in the US (the cold, the T, tipping, driving in snow). Students have a lot to say about this | |
