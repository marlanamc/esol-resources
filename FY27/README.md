# FY27 classroom materials

Where things live. Each HTML file has a matching PDF for printing when one has been made.

```
FY27/
├── placecards/              Name placecards and binder labels
├── reference-sheets/        Grammar Companion (the app reads this file, don't move it)
└── worksheets/
    ├── warmups/             Arrival warm-ups, one per class day (see warmups/README.md)
    │   ├── print/             2 copies per landscape sheet
    │   └── classroom/         1 portrait copy, for Google Classroom
    ├── stations/            Tuesday practice stations
    │   ├── kit/               Reusable station materials (station kit, if-dice game)
    │   └── weekNN/            One folder per week: packet, key, leader guide, reading, real-world doc
    ├── group-handouts/
    │   ├── phrase-banks/      Phrase bank + sentence starter worksheets
    │   ├── verb-chart/        Verb charts, pocket verb book, its key and slides
    │   ├── scavenger-hunts/   Hunts and their answer slides
    │   └── how-to-succeed-in-esol-3
    ├── readings/            Stand-alone readings
    ├── assessments/         Unit speaking assessments
    ├── unit-checklists/     Unit checklist builder (writes to output/pdf/)
    └── fact-sheets/         PROTECT Act sheets for students and staff (pictures in images/)
```

File names: `weekN-dayM-YYYY-MM-DD` for dated materials (Day 1 = Tuesday, Day 2 = Thursday).
New Tuesday stations go in a new `stations/weekNN/` folder (two-digit week number).
