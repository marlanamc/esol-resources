The 4 conditionals

Zero · Always trueREAL
If + V1,V1
If I drink coffee at night, I don't sleep well.
First · Real futureREAL
If + V1,will + V1
If it rains tomorrow, I will take the bus.
Second · Imagine nowNOT REAL
If + V2,would + V1
If I won the lottery, I would buy a house.
Third · Imagine the pastNOT REAL
If + had + V3,would have + V3
If I had left home earlier, I would have caught the bus.

How to play

1Mix it. Flip some top halves and some bottom halves. Read your new sentence out loud.
2Check it. Same color? Say it to a partner. Different colors? The top is the boss. Change the bottom verb so it matches.
If I won the lottery, I will take the bus. → If I won the lottery, I would take the bus.
3Cover it. Cover the bottom half with your hand. Your partner reads the top and finishes the sentence.
4Ask it. What do you do if…? · What will you do if…? · What would you do if…? · What would you have done if…?
Secret! Zero top + First bottom can be correct. Both tops use If + V1.
If I drink coffee at night, I will take the bus. ✓ (silly, but correct!)
Comma: If is first? Use a comma. If it rains, I take the bus.
