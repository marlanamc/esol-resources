If This, Then That: Zero + First Conditional

Keep this page. Use it to write on the back.

1. Two kinds of "if" After if: always V1 or V1-s. Never will.

Zero
always true
If + V1, V1
habits, facts, rules
First
one real future
If + V1, will + V1
plans, promises, warnings

2. How does it work? The important verbs are in black.

A. Zero: V1 + V1
Ifitrains,Itakethe bus.
If I drink coffee at night, I don't sleep well.
✗ If I am tired, I went to bed early.
B. First: NO will after if
Ifitrainstomorrow,Iwill takethe bus.
If you need help, I will come.
✗ If it will rain, I will take the bus.
C. If first? Use a comma.
If it rains,I take the bus.
I take the bus if it rains. (no comma)
✗ I take the bus, if it rains.
D. Remember
he / she / it + V1-s
If my son gets sick, I stay home.
I will = I'll  ·  will not = won't

5. Level up These work like First. After them: V1, not will.

unless = if not
I'll walk unless it rains.
= If it doesn't rain, I'll walk.
when / as soon as + V1
I'll call you as soon as I get home.
✗ as soon as I will get home
