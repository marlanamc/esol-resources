Absent Student Catch-Up Plan

One repeatable catch-up path for busy adult learners: required app tasks, make-up deadlines, and warm-up/announcement templates.

Absent Student Catch-Up Plan

Purpose

Adult ESOL students miss class for real reasons: work shifts, childcare, illness, appointments, and transportation. Absence should not become confusion, shame, or a reason to stop coming.

Next year's goal: every absent student opens the app and finishes the required weekly path — short enough to complete before the next class.

Students are expected to use Class Companion weekly (often daily) and can rent a Chromebook. Catch-up is not a separate system — it is the same This Week's Path with a make-up deadline. Students who missed class do not need a different set of instructions after September Week 2.

September onboarding (login, navigation, scavenger hunt): September App And Chromebook Onboarding Plan

  • Tuesday warm-up back = weekly plan on paper
  • App weekly path = ordered tasks with due dates
  • Class announcement = one place to post the same message every week
  • Weekly quiz = accountability without requiring perfect attendance

Core Principles

  1. Same path every week. Students should not have to ask "What did I miss?" every time. The structure repeats; only the topic changes.
  2. Minimum viable catch-up. Absent students do the tasks that protect next class — not a copy of everything that happened in the room.
  3. Make-up without shame. Language should sound like respect for adult life, not punishment for missing.
  4. App first — always. After September, the weekly path is the default. Warm-up and announcements point to the same place.
  5. Come back ready to participate. The goal is not perfect completion. The goal is: know the 6 words, know the grammar focus, and be able to try the speaking task.

    6. Student Message (Post In Class And App Every Week)

    Missed class? Do this before the next class:

    >

    1. Go to myesolclass.com and log in
    2. Open This Week's Path
    3. Complete the Required items you missed
    4. Know this week's 6 vocabulary words and 3 verbs
    5. Be ready for the quiz (or complete the make-up quiz by the extended deadline)

    >

    You do not need to redo partner speaking stations at home. You do need the language from the week so you can join class prepared.

    >

    Questions? Message me or ask at the start of the next class. Missing class is okay. Coming back confused is what we want to prevent.

    Catch-Up By Absence Pattern

    Missed Tuesday (intro day)

    Tuesday introduces the week. Absent students missed new vocabulary, grammar introduction, and stations.

    Do before Thursday:

    1. Complete app path steps: topic opener + grammar micro-module + vocab + verbs
    2. Read the Tuesday warm-up front (get from classmate, teacher, or posted PDF)
    3. Complete required app tasks due before Thursday
    4. Optional: write 3 sentences using 3 of the weekly vocab words

      5. At Thursday class: Join review and speaking. You do not need to prove you did Tuesday's stations.

      Missed Thursday (review + quiz day)

      Absent students missed retrieval practice and may have missed the live quiz.

      Do before next Tuesday:

      1. Complete the weekly quiz in the app (make-up deadline: Monday 6pm or next class start)
      2. Review the 6 words and 3 verbs in the app
      3. Skim the Thursday warm-up if posted (real-world literacy + writing model)
      4. Complete any still-open required app path items

        5. At next Tuesday: Start the new week. Do not carry shame about missing Thursday.

        Missed both days

        Do before next Tuesday:

        1. App weekly path: all required items for that week
        2. Weekly quiz (make-up deadline: Monday 6pm)
        3. One short written reflection: "What is one useful thing from this week's topic for my life?" (5 sentences max)

          4. Do not assign: a custom packet, a long essay, or a mandatory office visit unless the student asks for help.

          Missed quiz day only (attended Tuesday, absent Thursday)

          Most common partial absence pattern.

          Do:

          1. Quiz in app by extended deadline
          2. 10-minute vocab + verb review in app

            3. Do not: reassign the whole week.

            Make-Up Deadlines (Suggested Policy)

            ItemRegular deadlineMake-up deadline
            Weekly app path (required steps)Thursday before classMonday 6pm
            Weekly quizThursday in class / Thursday 6pmMonday 6pm
            Optional enrichmentNoneAnytime

            Rules:

            • Make-up deadlines are automatic, not negotiated case-by-case (less email, less shame).
            • Late work is accepted without explanation required.
            • No point penalty for absence-related make-up within the window.
            • After the window: student can still complete for feedback, but may not count for that week's quiz grade — teacher discretion.

            Teacher Weekly Routine (About 5 Minutes)

            Same tasks every week — no custom makeup plans per student.

            Before Tuesday

            • [ ] Confirm app weekly path is published with due dates
            • [ ] Confirm Tuesday warm-up back lists: topic, 6 words, 3 verbs, grammar, homework, quiz date
            • [ ] Post or update class announcement using the Weekly Catch-Up Template (below)

            After each class

            • [ ] Note who was absent (attendance)
            • [ ] No individual makeup assignment unless student has an unusual extended absence (2+ weeks)

            Optional (once a month)

            • [ ] Review: are absent students completing app path at similar rates to present students?

            Weekly Catch-Up Announcement Template

            Post to class announcement (and repeat in app instructions) every week. Replace bracketed fields only.

            **Week [##]: [Topic]**

If you missed class, do this before [next class day]:
1. Open Class Companion → This Week's Path
2. Finish required items: [list 2–4 item names]
3. Learn the 6 words: [word1], [word2], [word3], [word4], [word5], [word6]
4. Quiz make-up deadline: [Monday 6pm / date]

You do not need to make up partner stations at home. Come to the next class ready to use the words and grammar.

Questions? Ask me at the start of class.

            Warm-Up Back Template (Catch-Up Block)

            Add a fixed box to every Tuesday warm-up back:

            IF YOU MISSED CLASS
1. Open Class Companion → This Week's Path
2. Finish required app tasks (due [date])
3. Learn the 6 words + 3 verbs on the front of this sheet
4. Quiz make-up: [date/time]
Partner stations are in-class only. App + vocab + quiz = your catch-up.

            Students who were present also benefit — they see the same expectations.

            Connection To Gamification

            Do not tie primary rewards to perfect attendance for this population.

            Better milestones:

            • completed weekly path on time (present or absent)
            • quiz completed (including make-up)
            • vocabulary retained on Thursday review
            • returned after absence without dropping out

            Optional soft recognition: "Back on track" after completing catch-up path — not "perfect attendance."

            What This Plan Does Not Try To Solve

            • Students who disappear for weeks (needs advisor/outreach, not a worksheet)
            • Replacing live speaking practice fully at home
            • Legal attendance reporting requirements (separate from learning catch-up)

            For extended absence (2+ weeks), use a simplified re-entry: current week's path only + short teacher check-in. Do not assign a backlog of every missed week.

            Working Thesis

            Busy adults do not need more guilt about attendance. They need one repeatable way back in — short, dignified, and tied to the same weekly path everyone else uses.

            If catch-up is always the same shape, students spend their limited time doing the work, not figuring out what the work is.
