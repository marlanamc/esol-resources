Summer 2026 Planning

Class Improvement Plan

The core teaching vision: community class first, speaking-centered lessons, meaningful homework, quizzes, and adult-life English.

Next Year Class Improvement Plan

Purpose

This is a summer planning document for improving next year's ESOL class. The main goal is to make the class feel more useful, adult, and community-centered while still building strong English foundations.

Students should leave each week feeling like they learned something real about life, work, school, health, housing, money, or their rights. Grammar and vocabulary should support that goal instead of becoming the whole point of the week.

The class should also become much more speaking-centered. Students need more conversations, more partner practice, more role-plays, more stations, and fewer worksheets.

Core Principle

This is a community school first and foremost.

English matters, but the class should also help students handle real adult situations:

  • calling health insurance to check a prescription price
  • filing a complaint with the Department of Labor
  • understanding a workplace notice
  • asking a pharmacy or clinic the right questions
  • reading a lease, bill, letter, form, or school message
  • explaining a problem clearly and respectfully
  • knowing what agency, office, or person to contact

The best weeks should feel like: "I learned English, and I learned how to do something useful."

The class should also protect students' time. Every quiz, test, homework assignment, app activity, and worksheet should have real meaning behind it. Nothing should be assigned just to assign something. If students are asked to do work, it should truly matter.

1. Rethink The Grammar Guides

The medical grammar guides feel like the right model because they are not only grammar-heavy. They teach practical real-world topics at the same time.

At the same time, many grammar guides are too long. They can feel like 15-page grammar packets with long mini-quizzes attached. Next year, the goal should be shorter microlearning modules that students can finish, remember, and revisit.

Direction

Grammar guides should become topic-based learning journeys, not grammar explanations with a few examples added. But those journeys do not need to live on one long page.

Instead of one giant guide, consider a learning path made of smaller modules:

  • short concept lesson
  • real-world example
  • quick practice
  • speaking task
  • timeline check when relevant
  • short quiz or exit check

Each guide should answer:

  • What real situation is this grammar helping students handle?
  • What adult-life topic are students learning?
  • What documents, calls, conversations, or decisions might they actually face?
  • What should students be able to do by the end?

Microlearning Direction

Each module should be small enough that students can complete it without losing the thread.

Possible module structure:

PartGoal
Learnone clear idea
See itone real-world example
Try it3-5 quick practice questions
Say itone partner/speaking task
Check itshort exit question or mini-quiz

Long mini-quizzes should be reconsidered. Quizzes can still matter, but they may work better as short checks inside a path instead of one large quiz at the end of a long guide.

Summer Work

  • [ ] Review the existing grammar guides and identify which ones feel too grammar-heavy.
  • [ ] Prioritize the guides that need the biggest transformation.
  • [ ] Use the medical guide style as the model: real setting, real problem, real language, short grammar explanation.
  • [ ] Explore microlearning modules instead of long single-page grammar guides.
  • [ ] Sketch learning paths that connect several short modules together.
  • [ ] Reduce long end-of-guide mini-quizzes into shorter checks across the path.
  • [ ] For each guide, choose a real-life theme before rewriting the grammar content.
  • [ ] Keep the grammar clear, but make the topic meaningful.

2. Make Every Week Teach Real Adult Knowledge

Each week should have a practical topic students can explain or use by the end of class.

This does not mean every class becomes a civics lesson. It means the reading, listening, speaking, grammar, and vocabulary should point toward something real.

Speaking should be the main way students process that real-world topic. If the topic is health insurance, they should practice the phone call. If the topic is workplace complaints, they should practice explaining the problem. If the topic is housing repairs, they should practice asking the landlord and following up.

Weekly Planning Question

Before planning the grammar, ask:

What useful adult-life skill or knowledge should students walk away with this week?

Then ask:

What English do they need in order to do that?

Possible Weekly Topics

  • how to file a workplace complaint
  • how to call health insurance about medication coverage
  • how to ask a landlord for a repair
  • how to read a pay stub
  • how to explain symptoms at urgent care
  • how to compare prices or fees
  • how to understand a school message
  • how to report a missed payment or billing mistake
  • how to ask for clarification politely
  • how to document a problem in writing

Summer Work

  • [ ] Build a list of practical adult-life topics for the year.
  • [ ] Match each topic to one grammar focus, one vocabulary set, and multiple speaking tasks.
  • [ ] Create a weekly planning template that starts with the real-world topic before the grammar.
  • [ ] Save useful real-world links, forms, scripts, and sample documents.

3. Make Speaking The Center Of Class

The class should revolve around speaking. Worksheets should be limited and purposeful. More class time should go to conversations, stations, speaking games, role-plays, interviews, problem-solving tasks, and repeated practice with useful language.

Direction

The default question for planning should be:

How will students say this out loud many times?

Students should not only understand the grammar or vocabulary. They should be able to use it in conversation with another person.

Tuesday Stations

Tuesdays should usually be station days.

Stations can include:

  • speaking games
  • role-play cards
  • partner interviews
  • vocabulary conversation practice
  • timeline tense sorting or sentence-building
  • grammar stations with short focused tasks
  • teacher-led correction or mini-conference station

The grammar can still be present, but it should live inside speaking and interaction whenever possible.

Worksheet Rule

Use very few worksheets.

Worksheets should only be used when they clearly support the speaking task, give students a record to keep, or help prepare for a quiz. They should not become the main class activity.

Summer Work

  • [ ] Build a Tuesday station rotation template.
  • [ ] Create reusable station types for speaking games, grammar practice, vocabulary, and timeline tenses.
  • [ ] Convert worksheet-heavy activities into conversation tasks where possible.
  • [ ] Create role-play card sets for common adult-life topics.
  • [ ] Add speaking routines to the weekly planning template.

4. Explore A Different Way To Teach Tenses

Students are not coming into class fresh. Most have already had at least two years of present simple, past simple, continuous, and some future. Next year should not spend a full month on present simple alone as if students have never seen it.

Tenses should be worked into the lessons more naturally and revisited constantly through real situations, speaking, timelines, and weekly practice.

Direction

Move away from long isolated tense units.

Instead of:

This month is present simple. Next month is past simple.

Try:

This week we are solving a real-life problem, and we will use the tenses we need to talk about habits, past experiences, current problems, and future plans.

Rules still matter. They give students confidence, language to explain what they are doing, and structure when English feels chaotic. But the rule should support communication, not become the whole lesson.

Balance To Aim For

Too Much RulesBetter BalanceToo Little Structure
memorizing forms without using themclear rule + real use + speaking practiceonly conversation with no correction
one tense isolated for weekstenses compared and revisited oftenstudents guessing with no pattern
worksheets firsttimeline, meaning, sentence, conversationno explicit grammar language

Teaching Questions

When planning tense instruction, ask:

  • What does this tense help students say in real life?
  • Have they already learned this before?
  • What actually needs review: form, meaning, pronunciation, question form, negative form, or word order?
  • Can this be taught through comparison instead of isolation?
  • Can students see it on a timeline?
  • Can they use it in a conversation today?

Summer Work

  • [ ] Review the yearly tense sequence and identify places where tense units are too isolated.
  • [ ] Decide which tenses need full lessons and which need spiral review.
  • [ ] Build mixed-tense weekly practice instead of single-tense blocks.
  • [ ] Create tense comparison routines using timelines.
  • [ ] Keep short rule explanations, but pair every rule with speaking practice.
  • [ ] Look for ways to teach present simple, past simple, continuous, future, and present perfect together through real topics.

5. Start Present Perfect Earlier

Present perfect should start near the beginning of the year instead of waiting until later. Students need repeated exposure over time because it connects to so many adult-life situations.

Why

Present perfect shows up in:

  • job interviews: "Have you worked in a kitchen before?"
  • medical forms: "Have you had surgery?"
  • housing: "Have you ever been evicted?"
  • school meetings: "Has your child received services before?"
  • workplace problems: "I have asked my manager three times."

Direction

Introduce present perfect early in a practical way. Do not wait until students are "ready" for the whole grammar explanation. Start with useful sentence frames and build from there.

Summer Work

  • [ ] Decide where present perfect should first appear in the year plan.
  • [ ] Create simple early-year present perfect routines.
  • [ ] Add present perfect review questions to later units.
  • [ ] Connect present perfect to timeline tense visuals from the beginning.

6. Perfect The Parts Of Speech Guide

The parts of speech guide needs to become a serious early-year foundation. By May, students should not still be unsure what a noun is.

Goal

Students should be able to identify and use the most important parts of speech in real sentences:

  • noun
  • verb
  • adjective
  • adverb
  • preposition
  • pronoun
  • conjunction

Direction

The guide should be practical, visual, and repeated often. It should help students understand sentence structure, not memorize labels in isolation.

Summer Work

  • [ ] Rewrite or strengthen the parts of speech guide.
  • [ ] Add real-world examples from forms, signs, texts, school messages, bills, and workplace notices.
  • [ ] Create weekly mini-review routines for parts of speech.
  • [ ] Add parts-of-speech questions to weekly quizzes.
  • [ ] Build a simple diagnostic for the first weeks of class.

7. Integrate Timeline Tenses Into Weekly Practice

The timeline tenses work has been one of the biggest supports. Visualizing sentences changes how students understand tense.

Direction

Timeline practice should not be a separate occasional activity. It should become part of the weekly grammar routine.

Students should regularly answer:

  • When does this happen?
  • Is it finished or continuing?
  • Is it one moment, a repeated action, or a duration?
  • Does it connect the past to now?
  • What does the sentence look like on a timeline?

Summer Work

  • [ ] Add timeline tense practice to the weekly class flow.
  • [ ] Create short timeline warm-ups for each major tense.
  • [ ] Build review questions that ask students to match sentences to timeline visuals.
  • [ ] Add present perfect timeline practice early.
  • [ ] Use timelines in quizzes, not only in lessons.

8. Reduce Weekly Vocabulary To 6 Words

The vocabulary load may have been too heavy this year. Next year, try 6 words per week.

Proposed Routine

DayFocus
TuesdayIntroduce 6 words in context
ThursdayReview, retrieve, and use the same 6 words

Direction

The goal is deeper ownership, not more exposure. Six useful words that students can say, recognize, and use are better than a longer list they half-remember.

Weekly Vocabulary Rules

  • Choose words connected to the real-world topic.
  • Introduce words inside a situation, not as a list first.
  • Reuse the words in speaking, reading, and quiz questions.
  • Review the same words on Thursday.
  • Save extra words as optional support, not required vocabulary.

Summer Work

  • [ ] Test a 6-word weekly vocabulary structure.
  • [ ] Update weekly planning materials to support Tuesday introduction and Thursday review.
  • [ ] Create vocabulary retrieval routines for Thursday.
  • [ ] Decide how to track which words students should retain long-term.

9. Start Weekly Learning Quizzes In September

Weekly quizzes should start in September so the routine is normal from the beginning of the year. Instead of waiting until later or treating quizzes as a special event, students should understand that every week ends with a short check of the language and real-world topic.

Verb quizzes should expand into weekly learning quizzes that check the whole week.

Verb Load

Reduce verbs of the week to 3.

Three verbs is enough for repeated practice without taking over the whole week. The goal is for students to actually learn and use the verbs, not just memorize a longer list for a quiz.

Proposed Quiz Parts

  • 3 verbs of the week
  • 6 weekly vocabulary words
  • parts of speech review
  • timeline tense question
  • 2-4 comprehension questions about the real-world topic of the week

Direction

The quiz should help answer:

  • Did students understand the language?
  • Did students understand the real-world topic?
  • Can they use the vocabulary?
  • Can they recognize the grammar in context?
  • Are the foundational skills sticking?

Summer Work

  • [ ] Design a weekly quiz template.
  • [ ] Plan to begin weekly quizzes in September.
  • [ ] Decide which parts should stay the same every week.
  • [ ] Build a 3-verbs-per-week routine.
  • [ ] Add a small topic-comprehension section.
  • [ ] Include timeline tense questions.
  • [ ] Include parts-of-speech review.
  • [ ] Keep quizzes short enough to grade and review consistently.

10. Make Homework Clear And Accountable

Homework should be clearer next year, and the app can support that.

Instead of presenting app work as optional extra practice, some activities should be named as actual assignments with due dates. Students often want accountability. Clear homework does not infantilize adults when it is framed respectfully and connected to their goals.

Direction

Use the app to make homework visible, specific, and time-bound.

Students should be able to open the app and know:

  • what they need to do
  • why it matters
  • when it is due
  • whether it has been completed
  • how it connects to class

Homework Principles

  • Keep assignments short enough to be realistic.
  • Make homework directly connected to the week.
  • Assign specific tasks, not vague optional practice.
  • Use due dates.
  • Review or reference homework in class so students know it mattered.
  • Allow make-up work without shame.
  • Treat accountability as adult respect, not punishment.
  • Do not assign busywork. Every homework task should have a clear reason.

Student-Facing Message

The message to students should be:

I am not giving this to you just to give you homework. I am not going to waste your time. This matters because it helps you use English in class, at work, at home, or in the community.

Possible Weekly Homework

  • 6 vocabulary words practice
  • 3 verbs of the week
  • short microlearning module
  • timeline tense check
  • -ed endings listening or sorting practice
  • weekly quiz review or retake
  • short reflection connected to the real-world topic

Summer Work

  • [ ] Design a weekly app homework template.
  • [ ] Decide which app tasks are required and which are optional enrichment.
  • [ ] Add clear due dates to required assignments.
  • [ ] Build a simple teacher view for completion tracking if needed.
  • [ ] Create language for explaining homework accountability respectfully to adult students.
  • [ ] Decide how make-up work and late work should function.

11. Practice -ed Endings Every Day

Every class day should include practice with -ed endings. Yes, every day.

This may be one of the biggest struggles in teaching English. Students need to hear the endings, say them, repeat them, and build the instinct until they just know what sounds right.

Direction

Make -ed endings a daily pronunciation habit, not an occasional phonics lesson.

The routine can stay very small. It does not need to take over class. The key is repetition over time.

The usual "voiced vs. unvoiced" explanation may not be the best teaching method for this class. It is linguistically accurate, but it can be too abstract and confusing. Summer planning should focus on finding a more teachable approach that students can hear, feel, and use without needing technical vocabulary.

The Three Sounds

Repeat the three -ed endings over and over:

SoundExamplePattern
/t/worked, helped, askedafter voiceless sounds
/d/called, played, cleanedafter voiced sounds
/id/wanted, needed, decidedafter /t/ or /d/

The chart is useful for teacher planning, but it may not be the first explanation students need.

Teaching Approach To Explore

Try building the routine around sound groups, listening, and repetition:

  • "one extra syllable" vs. "no extra syllable"
  • clapping the syllables: worked = 1, wanted = 2
  • listening pairs: worked/wanted, called/needed, helped/decided
  • mouth practice with simple groups: helped, worked, asked; called, cleaned, played; wanted, needed, decided
  • color-coding the three endings instead of explaining the voicing rule first
  • using sentence rhythm: "I worked yesterday" vs. "I wanted help"
  • having students repeat common phrases until they sound familiar

Daily Routine Ideas

  • quick listen-and-repeat at the start of class
  • sort 3-6 verbs by -ed sound
  • add the 3 verbs of the week to the -ed chart when possible
  • use -ed endings during timeline tense practice
  • include one -ed pronunciation question on weekly quizzes
  • have students say a past-tense sentence to a partner
  • correct -ed endings during speaking stations without stopping the whole conversation

Summer Work

  • [ ] Create a daily 3-minute -ed ending routine.
  • [ ] Build a reusable -ed sound chart.
  • [ ] Find or design a student-friendly way to teach -ed endings without relying on "voiced vs. unvoiced" terminology.
  • [ ] Choose high-frequency regular verbs for repeated practice.
  • [ ] Add -ed pronunciation checks to weekly quizzes.
  • [ ] Add -ed practice to Tuesday stations and Thursday review.
  • [ ] Create teacher correction language for quick, low-pressure pronunciation feedback.

12. Rethink Gamification Around Individual Progress

Gamification should focus more on individual motivation and regular usage, not only competition against the class.

The workout studio app model is useful: it shows the total number of classes attended and celebrates milestones. Students may be more motivated if they can see their own history, consistency, and growth over time.

Direction

The app should help students think:

I am building something. I can see my progress.

This could be more motivating than only seeing where they rank compared with other students. Competition can still exist, but the main reward system should help each student notice personal effort and consistency.

Possible Individual Milestones

  • total classes attended
  • total activities completed
  • total weekly quizzes completed
  • weeks active in a row
  • first 5 quizzes completed
  • first 10 activities completed
  • 25, 50, 75, or 100 total completions
  • perfect attendance for a month
  • improved quiz score after a retake
  • completed all activities for a weekly topic

Possible App Ideas

  • lifetime activity count
  • personal milestone badges
  • progress timeline
  • streaks for weekly app use
  • "you have completed ___ activities this year"
  • "you have attended ___ classes"
  • private student progress dashboard
  • teacher view of individual consistency

Summer Work

  • [ ] Review the current points and leaderboard system.
  • [ ] Decide which individual milestones would actually motivate adult students.
  • [ ] Sketch a student progress dashboard focused on personal growth.
  • [ ] Consider attendance-based milestones if attendance data is reliable.
  • [ ] Add weekly quiz completion and app usage milestones.
  • [ ] Decide how much class competition should remain visible.

Possible Weekly Class Structure

This is a draft structure to test next year.

Tuesday

  • introduce the real-world topic of the week
  • introduce 6 vocabulary words in context
  • introduce or review 3 verbs of the week
  • practice -ed endings briefly
  • run station rotations as the main class structure
  • include speaking games, role-plays, partner conversations, and grammar stations
  • connect grammar to timeline visuals when relevant
  • use worksheets only as short supports, not the main activity

Thursday

  • retrieve and reuse the 6 vocabulary words
  • retrieve and reuse the 3 verbs of the week
  • practice -ed endings briefly
  • review the grammar through practical speaking tasks
  • use timeline tense practice
  • do a short weekly quiz or quiz review
  • assign or review clear app homework with a due date
  • close with a real-world speaking or writing task

Working Thesis

Next year's class should be less about covering grammar and more about building useful language through real adult situations.

The grammar still matters. The vocabulary still matters. The quizzes still matter. But they should all serve the bigger goal: students becoming more confident, informed, and capable in the community.
