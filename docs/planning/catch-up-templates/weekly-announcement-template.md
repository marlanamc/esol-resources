# Weekly Catch-Up Announcement Template

Post to the class announcement every week. Replace bracketed fields only.

```md
**Week [##]: [Topic]**

If you missed class, do this before [next class day]:
1. Open Class Companion → **This Week's Path**
2. Finish **Required** items: [list 2–4 item names]
3. Learn the 6 words: [word1], [word2], [word3], [word4], [word5], [word6]
4. Quiz make-up deadline: [Monday 6pm / date]

You do not need to make up partner stations at home. Come to the next class ready to use the words and grammar.

Questions? Ask me at the start of class.
```

## Teacher notes

- Mark in-class-only games and partner tasks as **Optional** on the class assignments page.
- Feature the weekly path items so they appear on the student dashboard.
- The app shows the make-up deadline automatically (Monday 6:00 PM).
