## W20: Past Perfect: What Had Already Happened

- **Slug:** `past-perfect`
- **Errors / warnings:** 0 / 0

### Scenarios

**She Had Already Done the Work** — Past Perfect = something that finished before another past moment. Use it to show which action happened first when telling a story about the past.

**had + V3: Putting It in Order** — Positive: subject + had + past participle Negative: subject + hadn't + past participle Every person uses had. There is no "hads" or "has had."

**When, Before, After, By the Time** — Four words help you show which action came first. Learn them and you can use Past Perfect naturally.

**Past Perfect vs. Past Simple** — Use Past Simple for one finished action in the past. Use Past Perfect only when you have two past actions and need to show which one came first.

**Your Work Story** — Past Perfect is natural in work histories: you talk about what you had done before the current job, and what had already happened before a key moment.

## W22: Second Conditional: What Would You Do?

- **Slug:** `second-conditional-what-would-you-do`
- **Errors / warnings:** 0 / 0

### Scenarios

**What If? Imagining Something Different** — Second conditional = an imaginary situation and its result. The situation is unlikely or not real right now.

**Building the Sentence** — Structure: If + past simple (if-clause) + comma + would + base verb (main clause). You can also put the main clause first: I would need a babysitter if my schedule changed. No comma needed when if comes second.

**What Would You Do? Advice at Work** — "If I were you..." is the most common way to give advice in English. Use were (not was) in formal and standard written English for all subjects in the if-clause when the situation is imaginary.

**Real vs. Imaginary: First vs. Second Conditional** — First conditional: If + present simple, will + base verb. The situation is real and possible. Second conditional: If + past simple, would + base verb. The situation is imaginary or unlikely.

**At Work: What Would Change?** — Women's History Month: in March, workers across the country talk about equal pay. Jennifer's line above is something many workers think about.
