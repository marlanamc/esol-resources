# Audit reports

Generated audit outputs live here on disk but are **not committed to git** (see
`.gitignore`). Re-run the matching npm script when you need a fresh report.

| Report | Regenerate |
|--------|------------|
| `mini-guides-w1-w18-review.md` | `npm run audit:mini-guides -- --report` |
| `mini-guides-w{N}-w{M}-review.md` | `npm run audit:mini-guides -- --report --min-week N --max-week M` |
| `grammar-dark-mode-sweep.md` | `npm run audit:grammar-dark-mode` |
| `answer-integrity-audit.md` | `npm run audit:answer-integrity -- --report` |
| `holiday-reference-audit.md` | `npm run audit:holiday-references` |
| `mini-quiz-quality-audit.md` | `npm run audit:mini-quiz-quality -- --report` |

Machine-readable findings from `audit:mini-guides` always land in
`tmp/mini-guides-audit/findings.json` (also gitignored via `/tmp/`).

**Kept in git:** one-off investigation notes and inventories that are not
regenerated by scripts (`GRAMMAR_AUDIT_REPORT.md`, `LEGACY_GUIDE_INVESTIGATION.md`,
etc.).
