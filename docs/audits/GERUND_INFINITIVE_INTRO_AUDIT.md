# Gerund/Infinitive Intro Audit

Scoring scale: `1` weak, `3` acceptable, `5` strong.

Columns:
- `C` = rule clarity
- `N` = signal-to-noise
- `E` = example quality
- `L` = cognitive load
- `R` = error prevention
- `P` = prompt quality

## Acceptance Checklist

- Every level now has one main teaching point.
- Checkpoint copy now describes review scope instead of congratulating the learner.
- Personal-response prompts are more varied across work, school, money, home, health, and communication.
- UI helper copy no longer repeats long summaries that already exist in the content data.
