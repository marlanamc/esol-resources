Maintaining this reference

Local review edition · Checked against local sources October 18, 2026 · Not deployed

This page is for maintaining the app, not classroom instruction.

  1. Edit the source lessons and course map. Preserve existing guide and activity identities when moving lessons.
  2. Run npm run quizzes:build, then npm run docs:grammar to refresh the local read-through previews and weekly plans.
  3. Run quiz validation, curriculum, scheduling, and points checks before release.
  4. Before any future production deployment, fetch GitHub and verify the source includes the latest origin/main. Recheck before promotion.
  5. The Vercel build does not seed the course map. Guide activity release, vocabulary synchronization, course-map synchronization, and quiz synchronization are separate reviewed database operations. Preview changes first and preserve completion evidence.
  6. After an authorized release, verify the live domain and source commit. Keep this work local until approved.

The local lesson preview exposes content and answer keys for teacher review. It does not authenticate, save answers, or award points.
