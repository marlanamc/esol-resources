Each week at a glance

Local review edition · Checked against local sources October 18, 2026 · Not deployed

Weeks 6–36 each have exactly one required core set of six words or phrases, with Word Lab practice. Weeks 1–5 stay as already taught. W15 and W30 deliberately recycle familiar words as required review sets. Each week has one required grammar guide plus practice. Unit month labels are curriculum groupings; the class dates below come from the school calendar and may cross month boundaries.

Reference page numbers match the printed Grammar Companion. Links open the matching page in a new tab; recommend only the named section, not every topic on that page. Classroom ideas are teacher suggestions. Award effort for meaningful attempts and revisions, with optional accuracy bonuses. Record classroom credit through the existing teacher points workflow; this local reference does not award points.
