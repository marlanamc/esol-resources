Local teacher reference · Updated November 21, 2026 · Release status

Weeks 6–36 each have exactly one required core set of six words or phrases, with Word Lab practice (except W11, Thanksgiving week: pattern games only). Weeks 1–5 stay as already taught. W15 and W30 deliberately recycle familiar words as required review sets. Each week has one required grammar guide plus practice; W11 has none (Thanksgiving) and W13 combines two short guides. Unit month labels are curriculum groupings; the class dates below come from the school calendar and may cross month boundaries.

Reference page numbers match the printed Grammar Companion. Links open the matching page in a new tab; recommend only the named section, not every topic on that page. Classroom ideas are teacher suggestions. Award effort for meaningful attempts and revisions, with optional accuracy bonuses. Record classroom credit through the existing teacher points workflow; this local reference does not award points.
