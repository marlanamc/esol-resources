Things to watch
  • April is the densest month. W29, W30 and W31 are three of the hardest points of the year back to back. W30 has catch-up time built in; check those quiz scores.
  • W32 used to → W33 be used to is a classic confusing pair. W33's "Don't Mix Them Up" page targets it; check the W33 quiz.
  • Modals take five guides (W8, W17, W21, W28, plus W7's optional suggestions). If W21 is ever freed up, relative clauses (who, that, which) are the biggest gap and suit the workforce unit.
  • W25 to W27 vocab looks shuffled. W25's set is pay words (gross pay, deductions, benefits), which fit W27's pay stubs better. The mar-17-19 and mar-24-26 topics also look swapped: "Communication & Feedback" holds rights words (comply, violate) and "Rights, Rules & Advocacy" holds feedback words.
  • Some weeks have no vocab set: W13, and the catch-up and review weeks W15, W22 and W30. W14 has no verb quiz.
  • Verb quiz numbers don't follow week order in the fall. W7 tests Quiz 7 (write, send), W8 Quiz 4, W9 Quiz 5, W10 Quiz 6, W11 Quiz 9, W12 Quiz 10, W13 Quiz 11, W15 Quiz 8. The comments in verb-quiz-plan.ts no longer match the weeks either.
Keeping it in sync

When a guide changes

  • Rebuild the quizzes with npm run quizzes:build. CI fails if a guide changes without it (check:generated). Students see the new questions after quizzes:sync -- --apply.
  • The course map does not sync on deploy. vercel.json uses its own build command, so after merging an edit to src/lib/course-map-data.ts, run node --env-file=.env --import tsx prisma/seed-course-map.ts. It writes immediately and removes map items that are no longer in the code.
  • The Week by week page is a snapshot. It was built from the course map, scripts/vocab/weekly-vocab-data.js and src/data/verb-quiz-plan.ts; update it by hand if those change.
  • A new guide needs a released activity row, or the finished-guide checkmark won't save. Run scripts/course-map/ensure-guide-activities.ts; it previews first and is safe to re-run.
  • Production writes need ALLOW_PROD_DB_MUTATION=yes CONFIRM_DB_HOST=db.prisma.io and node --env-file=.env --import tsx ....
